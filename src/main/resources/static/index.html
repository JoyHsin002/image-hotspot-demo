让一张普通图片，变成可配置的商品导览场景

上传门店、展厅或 2D 平面图，在图片上点击添加点位。拖拽微调、关联商品、保存草稿并发布，展示页会按相对坐标自适应渲染。

工作流

四步完成一个互动场景

01

上传底图

支持 PNG、JPEG、GIF、WebP，图片和数据都保存在本地目录。

02

点击打点

点击图片新增点位，拖拽或方向键调整，坐标使用 0～1 比例保存。

03

关联商品

从后端 Mock 商品库搜索选择，也可以手工配置商品详情。

04

保存并发布

草稿和线上发布版本分离，展示页面可分别预览两种数据。
